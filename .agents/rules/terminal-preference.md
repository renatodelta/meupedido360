# Preferências de Terminal do Usuário

- **Shell Preferido**: Git Bash (Sintaxe Bash / Linux).
- **Formatos de Comandos**: Sempre forneça instruções e comandos no formato **Git Bash**:
  - Usar `cp` ao invés de `Copy-Item` ou `copy`.
  - Usar `rm -rf` ao invés de `Remove-Item` ou `del`.
  - Usar `mv` ao invés de `Move-Item`.
  - Usar `npm` diretamente ao invés de `npm.cmd`.
